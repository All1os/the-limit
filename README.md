# The Limit

Prototype of The Limit: a push-your-luck card game for 3-5 players in an underground casino, where the lowest score each round is eliminated.

| File | What it is |
|---|---|
| `GDD-prototype.md` | Prototype rules and full card lists |
| `The-Limit-GDD-v0.1.docx` | Word copy of the GDD |
| `kaynak-The-Limit-orijinal.docx` | The original draft |
| `tts/` | Tabletop Simulator build: card images, the save (`tts-dosyalari/THE-LIMIT-prototype.json`) and the script that builds them (`kur.py`) |

## Tabletop Simulator save

Card images load from Steam Cloud, so the save file is all you need.

1. Copy `tts/tts-dosyalari/THE-LIMIT-prototype.json` into Tabletop Simulator's Saves folder (on a Mac: `~/Library/Tabletop Simulator/Saves/`).
2. In Tabletop Simulator, open it from the Save & Load menu.
