# Changelog

All notable changes to The Limit prototype. Each version is also a GitHub release.

## Unreleased

- File and folder names, code comments and script messages are now in English (for example `kur.py` is now `build.py` and `tts-dosyalari/` is now `output/`). The game itself did not change.
- Added this changelog and a link to it in the README.

## v0.1 (2026-10-05)

- Prototype GDD (`GDD-prototype.md`) written from the original draft: full rules, a 50-card main deck plus 6 reserve NPC Triggers, 20 NPC cards, 5 characters and 5 secret objectives.
- 14 rules the draft left open are filled in as assumptions A1-A14 (GDD §12). The designer still has to confirm them.
- Tabletop Simulator build made with `tts/build.py`: card images and backs, tokens, board images and the save file `tts/output/THE-LIMIT-prototype.json`.
- Word copy of the GDD: `The-Limit-GDD-v0.1.docx`.
